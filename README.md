# 🤖 AI ChatBot

An AI-powered chatbot web application built using React, FastAPI, Google Gemini AI, and Supabase. The application provides an interactive chat interface where users can communicate with an AI assistant and receive AI-generated responses.

### ⚙️ Installation and Setup

Prerequisites

- Python 3.10 or later

- Node.js and npm

- A Google Gemini API key

- A Supabase project

### Technologies Used
- React (Vite)
- Python (FastAPI)
- Google Gemini API
- Supabase
- Tailwind CSS

### Features
- Chat with an AI assistant
- Generate responses using Gemini AI
- User authentication with Supabase
- Database integration for storing application data

### How to Run

**Backend**
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```
